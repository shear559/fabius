# Contributing

Fabius takes bug reports, questions and corrections. It does not take code: unsolicited pull requests that add or change Fabius are not accepted. That is the maintainer's policy; the [LICENSE](LICENSE) grants personal, non-commercial use of the published plugin only.

The most useful thing you can send is a correction. The docs make measured claims (benchmark figures, test counts, model names), and a wrong one is worth an issue. Every kind of report has its channel in [SUPPORT.md](SUPPORT.md).

Want to build on Fabius, or use it for professional or client work? [Open an issue and ask](https://github.com/shear559/fabius/issues/new/choose). That needs written permission, and a yes is not guaranteed.
