# Fabius — identity

**Created by Ariel Shemesh.** One set of rules above every model.

Fabius is a coordinated library of instructions and local helpers for people building with AI agents. A router selects relevant expertise from fifteen skills, assigns responsibilities and guides the work from the request through verification and approved project memory.

The model provides reasoning and generation. Its host provides instruction loading, tools, storage and permissions. Fabius provides the working method. It does not change model weights or supply a separate hosted model.

## Scout wide. Strike narrow.

Understand the task and its context. Select the skills it needs. Build the smallest complete result. Check the result with available tools. Preserve useful project decisions where storage and permission allow.

The design goal is focused, consistent work with less unnecessary effort. That is an objective, not a published performance measurement.

## Public presentation

Lead with the working system, the skill responsibilities and the four interactive demonstrations. Show what the visitor can inspect and try. Label a browser simulation, a local check and a live model execution accurately.

Keep the green visual identity, clear typography and purposeful motion. Model names identify possible engines in a compatible host; they do not imply universal compatibility, affiliation or endorsement.
