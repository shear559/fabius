# Credits and source history

Fabius's current operating rules, local runtime and capability helpers are maintained in this repository. The original capability implementations are mapped to executable checks in [capabilities.json](capabilities.json). Research, external tools, brands and upstream projects remain the work of their respective authors.

Earlier releases included third-party source trees, sometimes with Fabius names substituted inside them. Those substitutions did not make the files original. The 3.0.0 implementation replaces those bundled capabilities with Fabius-authored procedures and code. [retired-upstream.json](retired-upstream.json) preserves the eleven former sources, their sixteen old directories, licence identifiers and missing historical pins. Their original files and notices remain available in signed release [v2.8.3-sealed](https://github.com/shear559/fabius/tree/v2.8.3-sealed); they are absent from the current package.

The table below preserves the learning history. A reference to a project is not a claim that Fabius implements its entire framework, bundles it, or owns it. Current external tool recommendations need a fresh suitability and licence check before use. [upstream.json](upstream.json) records inspected revisions for the seven currently registered source-informed references; it is not an exhaustive provenance claim for every historical research input.

Fabius's own work is covered by [LICENSE](../LICENSE). Any separately identified third-party assets or retained extracts keep their applicable terms. The release seal proves byte integrity and release-key attribution, not originality or copyright ownership.

The Bech32 tests retain eight BIP-173 vectors and one deliberately invalid variant. [retained-test-data.json](retained-test-data.json) identifies the exact literals, pinned source and [BSD-2-Clause notice](licenses/BIP-173-BSD-2-Clause.txt). These are public specification test data, not Fabius-originated examples. The [brand asset inventory](../assets/brands/README.md) separately records third-party marks.

## Current references and retired source

The current machine-readable registry uses `fabius-upstream/v1`. Each entry names an inspected source, a full revision when known, its owning Fabius reference and an explicit attribution paragraph. `node scripts/verify-upstream.mjs` checks those paths and the credit rows. Its adversarial tests retain synthetic MIT and Apache bundle cases so licence-closure validation remains tested even though no such source bundles remain.

The retirement registry is historical data. Its missing upstream revisions stay null; a local content hash is not an upstream pin. `node scripts/verify-original.mjs` checks that retired directories have not returned and that the original capability map resolves to implementations and tests. These checks establish package structure, not legal originality.

External products mentioned above have varied terms, including copyleft, noncommercial, branding-restricted and enterprise partitions. The table records the terms noted when the source was studied. It does not grant permission to install, redistribute, adapt or use an external product. Consult its current authoritative licence for a concrete use.
