Scope (Initial composition model). The eighteen parent rules \(\{\text{R1--R10},\ \text{M1--M8}\}\) motivate the following abstract composition. The argument assumes a total task classifier, feasible ownership constraints, explicitly resolved shared inputs, terminating primitive actions, and finite execution bounds. It describes policy structure; it does not certify the behavior of a model reading the policy.

Conditional analysis.

(a) Consistency. Strip surface vocabulary and nearly every gate is the same object: an expected-loss / value-of-information inequality \[ \mathbb{E}[L\mid\text{don't act}]-\mathbb{E}[L\mid\text{act}] \;>\; \text{cost}, \] instantiated on a different capability variable — a tool (R3: \(a-b>c_{\text{call}}\)), a second agent (M1: \(p_a(1-p_c)>c_{\text{agent}}\)), a branch (R7: \(\mathrm{EVSI}>c_{\text{search}}\)), a refine loop (R8/M4), a corrector depth (M3: \(qC_{\text{fail}}r'(0)>\kappa\)), a rewrite (M5), a stored fact (M6/M7/R9c/M8c). A family of sign-consistent inequalities, each in its own variable over disjoint capability axes, is jointly satisfiable and cannot contradict itself: this argument applies only when the relevant decision variables and constraints are actually separable. In a real task, shared budget, time, verifier outputs, and upstream admission decisions couple the choices. Shared inputs must be recomputed or resolved by the policy order; sign agreement alone proves no global optimum or conflict freedom. Tie-breaks are uniformly toward the cheaper action (R2's \(\le\), R3/M4's strict \(>\), M8c's strict \(<\)), so no two gates push opposite ways at a tie. The apparent "R2 minimize-machinery vs R7 branch-wide" tension dissolves on variable-counting: R2 sets the rung-admission bit (whether a rung enters), R7 sets the branch-width (how wide, once admitted) — orthogonal coordinates. Execution invariants R5 (grounding) and R6 (plan-then-bind) constrain the order of events, not whether any capability is added, so they live in a third, disjoint coordinate. Memory rules (M6–M8, R9–R9c) act only on the store/window variable. Under these separability assumptions the predicates can coexist. R13 supplies a separate conditional ownership argument; it does not establish that natural-language contracts obey locality.

(b) Completeness. R1's label space \(\{0,1\}^3\) has eight possible labels: given the measurability assumption in R1, every task lands in exactly one nonempty level set (mutual exclusivity + exhaustivity of \(\ell^{-1}\)). R2's ladder is a totally ordered chain \(0\le n\le N\), and \(\rho\) assigns every cell a defined action, including \(000\mapsto\) parcus inline (the \(n=0\) rung). Every declared label has an action in this illustrative exclusive map. This is formal coverage, not proof that the labels capture every real task requirement or that the classifier chooses correctly. Current routing composes owners as described under R1 and R13.

(c) Composability + model-applicability. Order the firing relation \[ \text{parcus}\prec \text{R1}\prec(\text{R4 if ambiguous})\prec \text{R2}\prec \text{R3}\!\cdot\!\text{M1}\prec \text{R6}\prec \text{R5}\prec \text{R7}\!\cdot\!\text{M2}\prec \text{R8}\!\cdot\!\text{M3}\!\cdot\!\text{M4}\prec \text{M5}\!\cdot\!\text{M6}\prec \text{R9*}\!\cdot\!\text{M7}\!\cdot\!\text{M8*}. \] This is a strict partial order with parcus as floor and no back-edge, hence a finite acyclic DAG; a topological traversal visits finitely many nodes. Execution terminates only if primitive actions terminate and any internal loops have enforced bounds. Each rule's input is produced upstream (R1's bits feed R2; R2's admitted rung feeds R7's width; R6's schedule precedes R5's grounding check), so the abstract dependency order is defined. Estimating loads, costs, gains, or hit-rates in context does not establish calibration. A host must supply actual tools, observations, and enforcement; reading the policy alone does not guarantee execution of this DAG.

(d) Isolation of non-governing rules. The one qualitative rule R5 answers only admissible / inadmissible (its proof shows no argmax \(J\) exists) and is never traded against a score. The operational heuristics — R4 (scout: defer-and-average), R10 (emphasis trades breadth for adherence), M8b (a recency tie-break), and M2's non-associative fallback — carry no objective function and each enters fabius only as a shape (defer-and-average, emphasis-trades-breadth, monotone tie-break, merge-needs-a-semigroup). None sits on the load-bearing inequality of (a): they advise a decision the mathematical gates have already made, and they do not directly replace a quantitative threshold. They may change classification, candidate routes, or evidence, which can change downstream inputs and decisions. Their isolation is a rule of precedence, not a claim of causal independence. \(\square\)

In fabius. These arguments guide routing and maintenance. They establish neither universal routing accuracy nor automatic host compliance. Apply the actual evidence and authority gates, retain the mandatory verification floor, and verify any claimed bound against the concrete executor.
